Engineering meets search.

I’m a front-end developer based in Addis Ababa, working with clients in Ethiopia and remotely — currently including a UAE-based CX consultancy. Since 2022 I’ve delivered 20+ production projects for startups and enterprises: ERP dashboards, e-commerce storefronts and e-learning platforms.

Case 01 · ConsultCXM

Reusable React & Next.js delivery for a CX consultancy

  • Engineering
  • SEO
Role
Front-End Engineer
Timeline
2025 – Present
Context
UAE-based CX consultancy · Remote

Overview

ConsultCXM is a UAE-based customer-experience consultancy. I work remotely as a front-end engineer, building React and Next.js applications for varied client requirements and implementing technical SEO on the company’s own WordPress site.

Objective

Deliver new client builds faster without letting performance slip — and keep the company site technically sound for search.

What I did

  • Architected React and Next.js applications for varied client requirements, and standardised a reusable component library that shortened time-to-delivery on new builds.
  • Raised performance through code splitting and lazy loading.
  • Integrated third-party REST APIs with Redux / Context API state management, and added automated tests with Jest and React Testing Library.
  • Implement technical SEO changes on the consultcxm.com WordPress site from an external SEO agency’s implementation guide, and publish WordPress-ready thought-leadership articles.

Key decisions

  • Standardise shared UI as a component library instead of rebuilding it per project.
  • Split code and lazy-load non-critical parts so new features don’t grow the initial bundle.
  • Cover state-heavy API integrations with automated tests.

Tools & methods

  • Context API
  • REST APIs
  • Jest
  • React Testing Library
  • WordPress

Results
